# Layer Overview

`meta-qcom` is an OpenEmbedded/Yocto Project BSP layer for Qualcomm Linux
platforms. The layer metadata identifies the collection as `qcom`, sets its
priority to `6`, and declares `core` as a required layer dependency.

The source repository also contains machine configuration, recipe, class,
continuous-integration, and dynamic-layer directories. This proof documents
the layer metadata and one small shell utility without attempting to describe
every recipe.
